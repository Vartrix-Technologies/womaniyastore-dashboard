## 1. File Responsibility

### Primary Responsibility
Staff personal dashboard showing attendance status, daily task checklists, and attendance history calendar.

### Role in the System
- Entry point for non-admin staff after login
- Displays current shift status (clock in/out)
- Shows today's assigned checklists
- Provides access to personal attendance history

### What This File Intentionally Does NOT Do
- **Data fetching**: Delegates to child components (`AttendanceCard`, `TaskChecklistCard`, `AttendanceCalendar`)
- **Attendance actions**: Clock in/out handled by `AttendanceCard`
- **Checklist completion**: Handled by `TaskChecklistCard`
- **Other staff data**: Only shows current user's data

### Key Dependencies
| Dependency | Purpose |
|------------|---------|
| `@/context/AuthContext` | Current user profile (full_name) |
| `@/components/staff/AttendanceCard` | Clock in/out widget |
| `@/components/staff/TaskChecklistCard` | Daily checklist display |
| `@/components/staff/AttendanceCalendar` | Monthly attendance history |
| Shadcn UI | Card, Button, Accordion (imported but unused) |
| Lucide Icons | Calendar |

---

## 2. Execution Flow

### `StaffDashboardPage` Component

**Trigger:** Route navigation to `/me`

**Input Expectations:**
- User must be authenticated with valid profile

**Internal Steps:**
1. Read `profile.full_name` from AuthContext for greeting
2. Render attendance and task cards in grid
3. Toggle calendar visibility via local state

**Side Effects:**
- **State**: Single `showCalendar` boolean toggle
- **No DB access**: All data fetching delegated to child components

**Output/UI:**
- Header with personalized greeting
- 2-column grid (1-col on mobile): Attendance + Tasks
- Collapsible attendance history section

### State: `showCalendar`

**Trigger:** "View History" / "Hide" button clicks

**Behavior:**
- `false` (default): Shows compact card with "View History" button
- `true`: Expands to show full `AttendanceCalendar` component

### Child Component Delegation

| Component | Responsibility |
|-----------|----------------|
| `AttendanceCard` | Current shift status, clock in/out actions |
| `TaskChecklistCard` | Today's checklists with completion tracking |
| `AttendanceCalendar` | Monthly calendar view of past attendance |

**Note:** `TaskChecklistCard` is rendered twice with different props:
1. In header with `showCompactSummary={true}` - shows summary badge
2. In content with `compact={true}` - shows full checklist

## 3. Business Rules & Assumptions

### Explicit Business Rules

| Rule | Implementation |
|------|----------------|
| Personalized greeting | Falls back to "Staff Member" if no name |
| Calendar hidden by default | Reduces initial page load/complexity |
| Tasks and attendance side-by-side | Grid layout, stacks on mobile |

### Implicit Assumptions
- User is authenticated (protected route)
- Child components handle their own data fetching
- `profile` object available from AuthContext
- Staff role has access to this route

### Invariants
- Page is read-only except through child component actions
- Calendar toggle is purely visual (no data impact)

## 4. Risks & Edge Cases

### Low Priority

| Risk | Impact | Mitigation |
|------|--------|------------|
| Profile null on initial load | Shows "Staff Member" | Fallback with `\|\|` operator |
| Task card overflow | Clipped content | `max-h-[500px] overflow-y-auto` |
| Calendar lazy load | Slight delay on expand | Component only mounts when shown |

### Notes
- **Minimal risk profile**: This is a thin presentation layer
- No direct data mutations or complex state
- All business logic lives in child components

## 7. Critic Section: Premium & Modern Assessment

### What Works Well ✅

| Feature | Why It's Good |
|---------|---------------|
| **Thin Presentation Layer** | Only 91 lines—proper architecture, delegates to components |
| **Responsive Grid** | Attendance + Tasks side-by-side on desktop, stacked on mobile |
| **Lazy Calendar Load** | Only mounts when expanded—good performance pattern |
| **Personal Greeting** | "Welcome back, {name}!" adds warmth |

### What Feels Dated or Unpolished ❌

| Issue | Impact | Premium Comparison |
|-------|--------|-------------------|
| **Plain welcome message** | Generic, no context | Google shows time-of-day greeting, weather, etc. |
| **No quick stats** | Missing "you worked X hours this week" | Gusto shows paycheck preview |
| **Calendar hidden by default** | Requires click to see history | Premium apps show mini-preview |
| **No notifications area** | Missed tasks, announcements | Slack shows unread indicators |
| **Static layout** | Same every time | Notion shows recent activity |
| **No goal/progress tracking** | Just clock in/out | Fitness apps show streaks, achievements |

### Missing Premium Features

1. **Personalized Dashboard Widgets**
   ```
   ┌────────────────────────────────────────────────────┐
   │ Good afternoon, Priya! ☀️                          │
   │                                                     │
   │ THIS WEEK                    YOUR STREAK           │
   │ ┌─────────────┐              ┌─────────────┐      │
   │ │ 32.5 hours  │              │ 🔥 12 days  │      │
   │ │ worked      │              │ on time!    │      │
   │ └─────────────┘              └─────────────┘      │
   └────────────────────────────────────────────────────┘
   ```

2. **Quick Actions Bar**
   - Clock in (if not yet)
   - View today's tasks
   - See this week's schedule
   - Request time off

3. **Recent Activity Feed**
   - "You completed 5/6 tasks yesterday"
   - "Next paycheck: Friday"
   - "Team announcement: Store closed Sunday"

4. **Mini Attendance Calendar**
   - Show last 7 days inline
   - Green/yellow/red dots for status
   - No need to expand for quick view
